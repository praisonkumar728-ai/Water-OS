# EWICRS — Cinematic Film (4:49.9, 1920×1080, 30 fps)

Programmatically generated documentary-style film for the EWICRS research project.
Everything except your three screenshots is generated by the code in this folder.

## Rebuild the film
```bash
pip install numpy scipy opencv-python pillow soundfile kokoro-onnx
# Kokoro voice files -> assets/audio/  (kokoro-v1.0.onnx, voices-v1.0.bin)
python3 scripts/generate_video.py            # narration, score, mix, 8 scenes, concat, mux, verify
python3 scripts/generate_video.py --skip-narration --jobs 2    # re-run without re-synthesising the voice
python3 scenes/scene_04_model_revision.py --preview 17,19.2    # JPEG previews of any moment (work/preview/)
```
Output: `output/EWICRS_CINEMATIC_FILM.mp4`; each scene also exists alone in `assets/generated_scenes/`.
A full render takes roughly 30–40 minutes on two CPU cores.

## Layout
| Path | Purpose |
|---|---|
| `lib/core.py` | typography, glass panels, glow/bloom, screenshot camera (`show_shot`), ffmpeg writer |
| `lib/engine3d.py` | small software 3D engine (terrain, tanks, pipes, particles, rain, reflections, labels) |
| `scenes/scene_0N_*.py` | one module per scene, each runnable alone |
| `scripts/narration.py` / `narration.txt` | narration lines and cue times / readable script |
| `scripts/make_narration.py` | Kokoro neural TTS, fitted to each cue slot |
| `scripts/make_music.py`, `mix_audio.py` | synthesised score + effects, ducked under the voice |
| `scripts/render_scenes.sh`, `generate_video.py` | orchestration and final verification |
| `assets/screenshots/` | your three original screenshots (untouched) |
